使い方

— USAGE

↑ 想定：ギャラリー／作品インデックス／ケーススタディ／章送り。「閉じる → 中身差替 → 開く」の 3 フェーズが 区切り として強く、見ているものが切り替わったことを言葉なく伝える。

01

2 ファイルをコピー

style.css の /* ─── COMPONENT ─── */ ブロックと、script.js の IIFE 全体を移植先へ。外部依存ゼロ、SVG だけ。

02

data-iris で宣言

ルートに data-iris、入れ替わる領域に data-iris-target を付ければ自動初期化。data-iris-blades（葉枚数）、data-iris-close / -hold / -open / -stagger でリズムを調整。

03

transition(swap) API

JS から el._iris.transition(() => swap()) を呼ぶと、close 完了時点で swap が走り、その後 open。route 切替などに直接組み込める。

CSS 変数

--iris-blade絞り blade の色（閉じきった画面色）#0a0a0a
--iris-edgeblade 同士の境界に薄く差すハイライトrgba(255,255,255,.04)
--iris-ease各 blade の easingcubic-bezier(.7,.0,.2,1)

アクセシビリティ

  • prefers-reduced-motion: reduce 時は blade の回転を止め、フェードでの切替に置き換える。
  • prev / next は <button>、キーボード ← / → 同等。サムネイル strip も <button> で直接ジャンプ可。
  • 遷移中は次の入力を無視（連打で多重実行しない）。ボタンに aria-label、SVG に aria-hidden。
